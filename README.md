📖 Project Overview

AstroVista is a responsive astronomy discovery and observation platform designed to help users explore the universe, learn about celestial objects, discover astronomy events, and organize their astronomical observations.

The platform provides an interactive and user-friendly experience for astronomy enthusiasts, students, and anyone interested in exploring space.

✨ Main Features

- Home Dashboard – Provides an overview of astronomy content and featured information.
- Solar System Explorer – Explore all eight planets in our Solar System.
- Planet Details – Discover information about individual planets.
- Astronomy Events – Explore astronomy-related events and information.
- Observation Planner – Plan and organize astronomy observation activities.
- Observation Journal – Record and manage personal observation entries.
- Astronomy Library – Search and explore astronomy-related learning resources.
- About AstroVista – Learn about the platform and its purpose.
- Responsive Design – Access the platform on desktop, tablet, and mobile devices.
