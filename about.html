Our Vision

To empower every student, budding astronomer, and science enthusiast with an elegant, clutter-free digital cockpit that transforms complex astronomical data into an accessible, inspirational journey across the cosmos.

Our Mission

Deliver a high-performance, dark-theme web platform adhering to strict UI/UX guidelines—enabling intuitive solar system exploration, structured celestial event tracking, and local-first stargazing session management.

Key Objectives

  • Catalog all 8 Solar System planets with rich telemetry.
  • Provide an illustrative celestial phenomena dashboard.
  • Facilitate interactive session planning with live preview.
  • Guarantee localStorage persistence with full CRUD actions.

HCI Evaluation Matrix

10 Software Interface Design Principles Applied

How AstroVista practically incorporates each fundamental software interface design heuristic to ensure an optimal, user-centered experience.

1. Consistency (Konsistensi)

Uniform typography (Space Grotesk headings, Inter body), identical 7-link navbar layout with dynamic active highlighting, identical card borders, button hover states, and standardized footer across all seven application pages.

2. Simplicity (Kesederhanaan)

Avoids decorative clutter or childish cartoon graphics. Presents deep scientific facts in scannable specification pills, structured comparison tables, and progressive disclosure modals without cognitive overload.

3. Visibility (Visibilitas Status)

Real-time cosmic clock displaying UTC and Julian Dates at the top of every page. Instant badge feedback for categories, observation counts, seeing scale ratings, and empty states that explicitly communicate system status.

4. Feedback (Umpan Balik)

Asynchronous toast notifications appear instantly upon saving an observation, updating records, deleting logs, or applying filter resets. Visual hover transitions signal clickability immediately.

5. User Control & Freedom (Kontrol Pengguna)

Users can edit any existing journal entry, delete individual records with a modal confirmation safeguard, export their database to local JSON files, print journal logs, or reset form inputs with a single click.

6. Accessibility (Aksesibilitas)

High contrast text compliance (WCAG AAA on primary copy against `#070b19` dark canvas), distinct focus outlines, semantic `

`, `
`, `
`, `
` markup, and aria-labels on toggles and buttons.

7. Easy Navigation (Kemudahan Navigasi)

Sticky navigation with active route highlights, smooth scrolling back-to-top floating button, breadcrumb clues, and cross-linking (e.g. clicking "Add to Planner" from Sky Events automatically pre-fills the planning form).

8. Error Prevention & Recovery (Pencegahan Kesalahan)

HTML5 form constraint validation with visual feedback for missing required fields; confirmation prompts before destructive deletions; graceful fallback defaults when localStorage is unpopulated.

9. Readability & Visual Hierarchy (Keterbacaan)

Clear typographic scale with `clamp()` responsive headings, distinct 1.6x line heights, grouped metadata in specification pills, and dark space glass surfaces that prevent glare during night observations.

10. User-Centered Design (Desain Berpusat Pengguna)

Designed around real astronomical observation workflows: Discover (Planets/Events) → Plan (Equipment, Seeing, Time) → Observe (Field Notes) → Archive (Journal & JSON Export) → Learn (Educational Library).
